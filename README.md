## 📌 Overview
This project is an **Intelligent Navigation Robot** built using Arduino.  
The robot can detect obstacles and autonomously navigate its environment using ultrasonic sensing.


---

## ⚙️ Features
- Autonomous obstacle avoidance  
- Real-time distance measurement  
- Smart navigation decisions  
- Simple and scalable design  

---

## 🧠 How It Works
The robot uses an **ultrasonic sensor (HC-SR04)** to continuously measure distance.  
When an obstacle is detected within a threshold, the robot automatically changes direction to avoid collision.

---

## 🔧 Components Used
- Arduino  
- Ultrasonic Sensor (HC-SR04)  
- Motor Driver (L298N)  
- DC Motors + Wheels  
- Battery Pack  

---

## ⚡ Challenges Faced
Power management was a key challenge.  
I couldn’t find lithium batteries, and my battery holder only supported 4 cells, which wasn’t enough to properly power the motors.  
This required experimenting with alternative solutions to ensure stable performance.
